Voltar para Montar prova

Guia JSON para IAs

Use este formato para preparar uma prova com os temas e as quantidades que a pessoa pediu.

Consulte os temas e gere a configuração

  1. Leia o catálogo de temas em JSON. Ele lista os nomes exatos e o número de questões definitivas e preliminares por ramo.
  2. Mapeie os pedidos da pessoa para os nomes do catálogo, respeitando o caminho completo. Se houver dúvida sobre o tema, peça esclarecimento antes de escolher.
  3. Estime quantas questões entram em cada ramo e confira se há questões suficientes. Por padrão, some definitivas e preliminares. Se a pessoa pedir só gabaritos definitivos, use apenas a contagem de definitivas.
  4. Entregue um único arquivo UTF-8 com a extensão .json. Em Montar prova, a pessoa escolhe Importar configuração JSON e confere o resumo.

Campos da configuração

  • versao deve ser 1.
  • quantidade é um inteiro de 1 a 200.
  • incluir_preliminares é opcional e aceita true ou false. O padrão é true.
  • temas é uma lista de matérias. Use [] para uma prova mista.
  • Cada item tem nome, copiado do catálogo, e peso, um número a partir de zero. Se omitido, o peso é 1. Use zero para excluir um tema. Cada grupo que recebe questões precisa de pelo menos um peso positivo.
  • filhos é opcional e contém a lista de assuntos, subtópicos ou detalhes do item pai. Use a mesma estrutura em todos os níveis. Uma lista vazia usa todas as questões do tema.

Use até quatro níveis, com nomes distintos em cada grupo. Os campos acima bastam para gerar a configuração. O banco fornece enunciados, alternativas e gabaritos.

Como distribuir as questões

Em cada grupo, divida o peso do tema pela soma dos pesos e multiplique pelo número de questões reservado ao grupo. Arredonde para baixo e distribua as sobras aos maiores restos fracionários. Em empate, vale a ordem do arquivo. Repita a conta dentro de cada tema que tenha filhos.

Se a pessoa pedir quantidades exatas, use essas quantidades como pesos e faça a soma dos pesos coincidir com o total daquele grupo. O exemplo abaixo gera 15 de Penal e 5 de Ética. Dentro das 15 de Penal, são 10 de Crimes contra a pessoa e 5 de Teoria do crime.

Baixar o exemplo em JSON

{
  "versao": 1,
  "quantidade": 20,
  "incluir_preliminares": true,
  "temas": [
    {
      "nome": "Direito Penal",
      "peso": 3,
      "filhos": [
        { "nome": "Crimes contra a pessoa", "peso": 2 },
        { "nome": "Teoria do crime", "peso": 1 }
      ]
    },
    { "nome": "Ética profissional e Estatuto da OAB", "peso": 1 }
  ]
}
